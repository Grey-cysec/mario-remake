1. Launch

Startup, renderer selection, art build, first level generation.

flowchart TD
    A["Run: python3 mario remake"] --> B["pygame.init() + read desktop size"]
    B --> C{"OpenGL 3.3 core available?"}
    C -->|"yes"| D["GL pipeline: frame -> 800x450 canvas -> bright pass -> blur -> bloom + grade + vignette -> fullscreen"]
    C -->|"no"| E["Fallback: plain scaled renderer"]
    D --> F["Build art: 96-pose run cycle, idle/jump/fall, walker, bat, boss,
4 parallax layers, tiles, pollen"]
    E --> F
    F --> G["Level 0 generated: ground, pits, bricks, spikes, coins,
checkpoints, walkers, bats, boss, flag"]
    G --> H["State = TITLE"]

2. Main loop

Runs 60 times per second — exactly one screen flip per frame.

flowchart TD
    A["Frame start: dt = min(1/30, clock.tick(60))"] --> B["Poll events"]
    B --> C{"Esc or Quit?"}
    C -->|"yes"| Z["pygame.quit() -> exit"]
    C -->|"no"| D{"Enter pressed
on title / game-over?"}
    D -->|"yes"| E["start_game(): lives=3, score=0,
regenerate level, state=PLAY"]
    D -->|"no"| F{"F1 pressed?"}
    F -->|"yes"| G["Toggle debug panel"]
    F -->|"no"| H["Track keydown / keyup / focus-loss
in event-based key set"]
    E --> H
    G --> H
    H --> I["update(dt)"]
    I --> J["draw() -> 800x450 canvas"]
    J --> K["present() -> shader composite
-> screen (1 flip per frame)"]
    K --> A

3. update() — one gameplay tick

Input → physics → collision → combat → entities → camera. Death and level-advance paths included.

flowchart TD
    A["update(dt)"] --> B{"state = PLAY?"}
    B -->|"no"| STOP["return (title / game-over frozen)"]
    B -->|"yes"| C["Tick timers: banner, flash, squash,
shot cooldown, invincibility, triple-shot,
ground-contact probe, run-phase, displacement"]
    C --> D{"Player dead?"}

    D -->|"yes"| E["Death fall + spin for 1.5 s"]
    E --> F{"Lives left?"}
    F -->|"no"| G["state = GAME-OVER"]
    F -->|"yes"| H["Lives -1, respawn at checkpoint
on safe footing, 2 s invincibility,
clear arrows/fireballs, reset coins,
killed mobs STAY dead"]

    D -->|"no"| I["Read keys (focus-safe)"]
    I --> J["Move: accel / friction, max speed"]
    J --> K["Jump: 0.12 s input buffer + 0.1 s coyote,
variable height, double jump, squash-stretch"]
    K --> L["Gravity, cap 900 px/s"]
    L --> M["move_x: swept tile collision"]
    M --> N["move_y: tile collision + 1 px ground probe
(stable ground state)"]
    N --> O{"F held?"}
    O -->|"yes"| P["shoot(): arrow every 0.35 s
=2 dmg to boss"]
    O -->|"no"| Q{"Touching spike
or below screen?"}
    P --> Q
    Q -->|"yes"| R["kill_player(): shake + flash"]
    Q -->|"no"| S["Coins, power-ups (+1 life / triple shot)"]

    S --> T{"Boss alive
at the gate?"}
    T -->|"yes"| U["Clamp player before flag"]
    T -->|"no"| V{"Past the flag?"}
    V -->|"yes"| W["Score +100, level +1,
regenerate level, flash"]
    V -->|"no"| X["Checkpoints: save respawn,
banner + heal burst"]

    H --> EN
    R --> EN
    W --> EN
    U --> EN
    X --> EN

    subgraph EN["Entities"]

4. Combat & scoring detail

Hit resolution for arrows, stomps, and enemy persistence.

flowchart TD
    A{"Arrow hits enemy?"} -->|"walker / bat"| B["One hit = kill, +30 score,
burst, body falls then freezes"]
    A -->|"boss"| C["Boss -2 HP, white flash,
+500 on kill"]
    A -->|"wall / 0.7 s old"| D["Arrow despawns"]
    E{"Player touches enemy?"} -->|"stomp: falling on top"| F["Enemy takes 1 dmg (stomp),
player bounces -380"]
    E -->|"side / below"| G["kill_player()"]
    H{"Enemy died?"} --> I["Stays dead for this level —
no respawn on death or reset"]

5. draw() + present() — every frame

Layer order top → bottom, then shader composite to screen.

flowchart TD
    A["draw()"] --> B["Sky gradient + sun halo

    B --> C["Tiles: only visible columns,

    C --> D["Coins with spin + glint, checkpoints, power-ups,

    D --> E["Enemies (animated, off-screen culled)"]
    E --> F["Arrows with glow trail"]
    F --> G["Player: idle / run 96-pose / jump / fall,
blink when invincible, squash-stretch, death spin"]
    G --> H["Pollen + HUD: score, lives, level,
power timer, progress bar"]
    H --> I["Overlays: title, level banner,
game-over, screen flash"]
    I --> J{"F1 panel open?"}
    J -->|"yes"| K["Debug panel: FPS graph, god mode,
buttons, physics + shader sliders"]
    J -->|"no"| L["present()"]
    K --> L
    L --> M{"GL available?"}
    M -->|"yes"| N["Upload canvas -> bright pass
-> horizontal + vertical blur
-> final: bloom, saturation, contrast,
vignette, film grain, letterbox"]

    N --> P["display.flip() — exactly once"]
    O --> P
